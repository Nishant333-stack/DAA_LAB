# Dijkstra's Algorithm - Food Delivery Route Optimization

## Problem Statement

A food delivery service needs to find the shortest route from a restaurant to a customer's location. The road network is represented as a weighted graph where locations are nodes and roads are edges with travel time as their weights.

This project implements Dijkstra's Algorithm to find the shortest route and minimum travel time from the restaurant to the customer.

## Dataset

The dataset used in this project is a weighted graph representing a food delivery road network.

Dataset file:

food_delivery_graph.txt

The dataset contains:

- Number of locations
- Number of roads
- Source location
- Destination location
- Travel time between connected locations

Each road is represented using:

source destination travel_time

The graph contains 6 locations and 9 roads.

Restaurant Location: 0

Customer Location: 5

## Algorithm

Dijkstra's Algorithm is a Greedy algorithm used to find the shortest path from a source vertex to other vertices in a weighted graph with non-negative edge weights.

The algorithm works in the following steps:

1. Set the distance of the source node to 0.
2. Set the distance of all other nodes to infinity.
3. Select the node with the smallest tentative distance.
4. Update the distances of its neighboring nodes.
5. Store the parent node for path reconstruction.
6. Repeat the process until the shortest path is determined.
7. Reconstruct the shortest path using the parent array.

## Greedy Approach

Dijkstra's Algorithm follows the Greedy approach because it always selects the unvisited node having the smallest tentative distance.

This choice helps in finding the shortest path when all edge weights are non-negative.

## Time Complexity

Using an adjacency list and priority queue:

O((V + E) log V)

where:

V = Number of vertices

E = Number of edges

## Space Complexity

O(V + E)

The graph, distance array, parent array, and priority queue require additional space.

## How to Run

Keep food_delivery_graph.txt in the same folder as food_delivery_dijkstra.cpp.

Compile the program:

g++ food_delivery_dijkstra.cpp -o dijkstra

Run the program:

./dijkstra

## Output

The program finds the shortest route from the restaurant to the customer and displays the minimum travel time.

For the given graph:

## Conclusion

Dijkstra's Algorithm was implemented successfully to find the shortest route in a food delivery road network. The algorithm uses a Greedy approach by selecting the location with the smallest tentative distance and updating the distances of its neighboring locations.

The implementation uses an adjacency list and priority queue, giving a time complexity of O((V + E) log V). It efficiently finds the minimum travel time between the restaurant and customer when all road weights are non-negative.
