# DAA Lab Assignments

Design and Analysis of Algorithms lab assignments, implemented in C++.

| No. | Assignment | Technique |
|-----|------------|-----------|
| [1](Assignment-1) | Merge Sort – Student Performance | Divide and Conquer |
| [2](Assignment-2) | Quick Sort – Netflix Dataset | Divide and Conquer |
| [3](Assignment-3) | Fractional Knapsack – Cargo Shipment | Greedy |
| [4](Assignment-4) | Dijkstra – Food Delivery Route Optimization | Greedy |
| [5](Assignment-5) | Multistage Graph | Dynamic Programming |
| [6](Assignment-6) | 0/1 Knapsack – Disaster Relief Allocation | Dynamic Programming |
| [7](Assignment-7) | University Timetable Scheduling (Graph Colouring) | Backtracking |
| [8](Assignment-8) | TSP – Delivery Route Optimization | Branch and Bound |

Each folder has the `.cpp` source, its dataset (if any), a `README.md`, and `output.txt` with a sample run.

Compile and run any assignment from inside its folder:

```bash
g++ <file>.cpp -o <name>
./<name>
```
