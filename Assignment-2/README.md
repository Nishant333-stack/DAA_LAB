# Quick Sort - Netflix Dataset

## Problem Statement

Netflix contains a large collection of movies and TV shows that can be arranged according to parameters such as title, rating, or release year. To efficiently sort a large number of records, an appropriate sorting algorithm is required.

This project implements Quick Sort to sort Netflix content according to its release year using the Divide and Conquer approach.

## Dataset

The dataset used in this project is the Netflix Movies and TV Shows dataset.

Dataset file:

netflix_titles.csv

The dataset contains information about Netflix movies and TV shows such as show ID, type, title, release year, rating, duration, and other details.

In this project, the release_year column is used for sorting.

## Algorithm

Quick Sort is a sorting algorithm based on the Divide and Conquer approach.

The algorithm works in three main steps:

1. Select a pivot element.
2. Partition the records around the pivot.
3. Recursively sort the left and right parts.

In this implementation, the last record is selected as the pivot.

## Time Complexity

Best Case: O(n log n)

Average Case: O(n log n)

Worst Case: O(n²)

## Space Complexity

O(n) in the worst case due to recursive function calls.

## Files

## How to Run

Keep netflix_titles.csv in the same folder as netflix_quick_sort.cpp.

Compile the program:

g++ netflix_quick_sort.cpp -o quick_sort

Run the program:

./quick_sort

## Output

The program sorts Netflix movies and TV shows in ascending order according to their release year and displays the Show ID, Type, Title, and Release Year.
