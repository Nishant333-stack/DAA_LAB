# Fractional Knapsack - Cargo Shipment

## Problem Statement

A shipping company has a container with limited weight capacity and needs to select products with maximum total value. Products have different weights and prices, and some can be loaded partially.

This project implements the Fractional Knapsack algorithm to maximize the total value of products loaded into the container.

## Dataset

The dataset used in this project is the Shipping Data dataset.

Dataset file:

shipping_data.csv

The dataset contains information about shipped products such as product name, price, weight, and other shipment details.

In this project, the price and weight of each product are used to calculate the price-to-weight ratio.

## Algorithm

The Fractional Knapsack algorithm uses the Greedy approach.

The algorithm works in the following steps:

1. Calculate the price-to-weight ratio for each product.
2. Sort the products in descending order of their ratio.
3. Select products with the highest ratio first.
4. Take the complete product if it fits in the remaining capacity.
5. If the complete product does not fit, take the required fraction of the product.
6. Continue until the container capacity is completely used.

## Greedy Strategy

The product with the highest price-to-weight ratio is selected first.

Price-to-weight ratio:

Price / Weight

This strategy helps in obtaining the maximum possible total value when fractional selection is allowed.

## Time Complexity

Ratio Computation: O(n)

Sorting: O(n log n)

Selection: O(n)

Total Time Complexity: O(n log n)

## Space Complexity

O(n)

The additional space is used for storing the product records and sorting them.

## How to Run

Keep shipping_data.csv in the same folder as fractional_knapsack.cpp.

Compile the program:

g++ fractional_knapsack.cpp -o knapsack

Run the program:

./knapsack

## Output

The program calculates the price-to-weight ratio of the products, sorts them according to the ratio, and selects full or partial products to maximize the total value within the container capacity.
